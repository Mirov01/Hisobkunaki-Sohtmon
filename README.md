# Ҳисобкунаки Сохтмон — Android

Ин лоиҳаи Android версияи веб-барномаи «Ҳисобкунаки Сохтмон»-ро дар WebView мекушояд.

## Сохтан
Лоиҳаро дар Android Studio кушоед ва Build > Build APK(s)-ро интихоб кунед.

Талабот:
- Android Studio
- Android SDK 35
- JDK 17
- Gradle (Android Studio онро идора мекунад)
